## 📱 Proje Hakkında
Cepofis, emlak ofisleri için geliştirilmiş bir portföy, müşteri ve randevu yönetim sistemidir. Mobil cihazlar üzerinden kolayca kullanılabilen bu uygulama, emlak danışmanlarının işlerini daha verimli yönetmelerini sağlar.

## ✨ Özellikler
- 📊 Portföy Yönetimi
  - Emlak ilanları ekleme ve düzenleme
  - Fotoğraf yükleme
  - Detaylı emlak bilgileri
- 👥 Müşteri Yönetimi
  - Müşteri kayıtları
  - İletişim bilgileri
  - İlgilendiği emlak türleri
- 📅 Randevu Takibi
  - Müşteri randevuları
  - Ziyaret notları
  - Hatırlatıcılar

## 🛠️ Kullanılan Teknolojiler
- Flutter
- Firebase
- Firestore
- Cloud Storage

## 🚀 Kurulum
1. Projeyi klonlayın
```bash
git clone https://github.com/serondev/cepofis-emlak-yonetimi.git
```

2. Bağımlılıkları yükleyin
```bash
flutter pub get
```

3. Uygulamayı çalıştırın
```bash
flutter run
```
